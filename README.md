# Pizza Sales Dashboard

## Overview

This project presents a management dashboard for analyzing pizza sales performance using Power BI.

The dashboard provides an overview of revenue, orders, pizza sales, and purchasing patterns throughout the year.

## Dashboard Preview

![Pizza Sales Dashboard](Images/dashboard-preview.png)

## Key Performance Indicators

* Total Revenue: 817.86K
* Average Order Value: 38.31
* Total Pizzas Sold: 49,574
* Total Orders: 21,350
* Average Pizzas per Order: 2.32

## Key Insights

* Orders are highest on weekends, especially Friday and Saturday evenings.
* The highest number of orders occurs in January and July.
* The Classic pizza category contributes the largest share of sales.
* Large pizzas account for the largest share of sales by size.
